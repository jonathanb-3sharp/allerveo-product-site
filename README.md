# Allerveo product site

The public product page for **Allerveo**, Caldova's once-daily treatment for seasonal and year-round nasal allergy symptoms.

> All content in this repository is fictional and was created for a Microsoft demo.

## What's in this repository

| Path | What it is |
|---|---|
| `index.html` | The product page |
| `content/launch-config.js` | The launch date shown on the page |
| `content/label-claims.js` | The label claims shown in the results section |
| `assets/css/caldova-theme.css` | Caldova brand colors and styles |
| `assets/js/main.js` | Puts the launch date and claims on the page |
| `assets/images/` | Product imagery |
| `docs/approved-claims/` | Text copy of the approved label claims deck |
| `docs/jira/` | Copy of the related Jira ticket (ALV-118) |
| `.github/copilot-instructions.md` | Rules GitHub Copilot follows when it changes this site |

## Preview the page
- **On your computer:** double-click `index.html` to open it in a browser.
- **Online:** this site is published with GitHub Pages (Settings → Pages).
